CardioCare-AIOps

Real-time cardiac monitoring platform · AWS EC2

Streams real MIT-BIH ECG beats as live vital signs for 9 ICU beds through Apache Kafka, every event AES-256-GCM encrypted. A hybrid engine (XGBoost classifier, adaptive Isolation Forest) flags events; OpenFaaS serverless functions fire Keycloak-JWT-secured, OPA-RBAC-gated alerts. 17 containers orchestrated with Docker Compose, one-command EC2 bootstrap. Reported 97.27% accuracy / AUC-ROC 0.9927 on the test beats.
